# 架构说明：实时推荐引擎

## 概述

本文档描述华为云上的实时推荐引擎架构，实现实时特征存储与推荐功能。

---

---

## 组件说明

### 1. 特征存储层

| 组件 | 用途 |
|------|------|
| OBS | 离线特征存储 |
| RDS MySQL | 在线特征存储 |

### 2. ML 训练层

| 模型 | 用途 |
|------|------|
| FM (Factorization Machines) | 协同过滤推荐 |
| XGBoost | 点击率预测排序 |

### 3. 流处理层

| 组件 | 用途 |
|------|------|
| DIS | 实时点击流数据接入 |
| Flink | 流数据聚合 (2分钟窗口) |

---

## 数据流

1. 离线特征写入 OBS
2. ModelArts 训练 FM + XGBoost 模型
3. 实时点击流 → DIS → Flink 聚合
4. 聚合结果存入 RDS MySQL (在线特征)
5. 实时推荐推理
